# AAC Uzbek Voice Recording Script

## Before you start

- Speak slowly and warmly — the audience is children aged 3–7.
- Keep the same distance from the mic for every take; do not change position mid-session.
- Record the entire session in one sitting, same room, same time of day.
- Leave about half a second of silence before and after each phrase.
- Neutral, friendly tone. Not exaggerated, not sing-song.
