## Additional Security Controls

### Rate Limiting
- Sliding-window rate limit on all `/api/v1/auth/*` endpoints.
- Implement per-IP rate limiting at ingress (nginx/Cloudflare) before GA.

### Security Headers (pending — tracked as issue #52)
Add to `main.py`:
```python
@app.middleware("http")
async def security_headers(request, call_next):
    response = await call_next(request)
    response.headers["X-Content-Type-Options"] = "nosniff"
    response.headers["X-Frame-Options"] = "DENY"
    response.headers["Referrer-Policy"] = "strict-origin-when-cross-origin"
    response.headers["Permissions-Policy"] = "camera=(), microphone=(), geolocation=()"
    return response
```

### Signed URL Expiry
- Media assets served via signed S3 URLs (15-minute expiry).
- `STUB #53` — implement S3 presigned URL generation in `modules/media/service.py`.

### Dependency Audit
```bash
cd backend && pip-audit  # add to CI as step after install
```

### Container Hardening
- Dockerfile: non-root user (`app:app` UID 1001) ✅
- Read-only filesystem: add `read_only: true` to docker-compose service config.
- No privilege escalation: add `security_opt: [no-new-privileges:true]` to compose.
